# M2 桌面预览版实现与验收

日期：2026-10-18。本文件保留 M2 阶段的本地实现与验收记录；当时开发工作区在 `main`，尚未提交或推送开发代码。后续公开仓库、云端构建与发布状态见 [M3 发布记录](M3.md)。原始设计中的资源目标、三平台打包等仍是后续验收项。

## 实现

- `tide-core::Service` 共用于桌面和 CLI watch：每文件夹串行、全局最多两任务；查询、恢复和同步使用同一队列，后台 Git 操作不在 UI 线程执行。
- 安装文件监听后才报告启动成功；监听配置目录并原子热加载，无效配置保留最后有效值。修改间隔可即时启用/关闭定时器，认证失败的停止重试状态不会被主题等无关变更解除。
- Slint 主界面包含文件夹列表、改动、分页历史、差异、整树恢复、历史文件导出、Ask 冲突选择、同步规则、运行记录和连接预览。添加向导可选本地路径、远端、分支；高级字段仍通过配置文件设置。
- Windows 托盘提供打开、同步全部、暂停、继续和退出；关闭留托盘时销毁窗口，重开重建。第二实例通过带随机令牌的 loopback IPC 唤起原进程，后台启动也可唤起。
- 深浅及系统主题、设备名、通知和开机启动设置已接入。开机启动仅在用户切换设置时注册；同一配置的桌面/watch 由锁互斥。
- 同步阶段和失败类型通过事件送到 UI，历史查询使用 folder ID/request ID 隔离旧响应；未保存设置不会被阶段事件覆盖，导出版本在打开弹层时固定。退出等待当前任务结束并释放锁。
- Slint 1.16.1 使用软件渲染和系统字体。“关于”中实际嵌入 AboutSlint，依据所下载版本的 `LicenseRef-Slint-Royalty-free-2.0` 桌面条款。

## Rust 复审及修复

本轮执行了 OCR delegate 范围预览和 Rust 规则获取，并由独立只读审查覆盖核心及桌面生命周期。没有把 Qt 技能用于 Rust，也没有把编译、Clippy、语义审查和运行测试混为一项。

修复了热加载定时器、文件夹 ID/名称歧义、Unix 同 blob 执行权限变更、大小写目录重命名及中断重放、认证停止状态被 reload 清除、停机忙循环、设置输入被后台事件覆盖、导出版本漂移、退出未等待任务以及 Linux 配置路径大小写冲突等问题。对应回归覆盖按平台条件执行，Unix 专属权限测试本机没有运行。

真实 GitHub 测试还暴露两项集成问题：

1. libgit2 默认连接没有启用代理自动检测。本轮在连接、fetch 和 push 一致启用 auto proxy，使现有代理环境可用；不修改用户全局 Git 或代理配置。
2. 系统 Git 的换行转换/属性和 stat 缓存可能把实际 CRLF 文件视为 clean。快照、连接预览和改动列表现在以原始 blob/模式复核，保留实际字节，并避免文件内容相同时因 clean filter 永久显示修改。

原始字节复核目前读取已跟踪文件，不符合原设计“只扫描改动文件”的性能目标；这是明确保留的优化项。

## 尚未验收或未实现

- macOS/Linux 仅配置构建/测试 CI，本机未执行，Windows 之外的托盘集成暂未启用。不能宣称三平台产品验收完成。
- 没有内置 keyring/令牌输入页，认证使用 Git 凭据助手、SSH agent 或指定私钥；真实远端本轮验证 HTTPS，未验 SSH/Gitee。
- 没有签名安装包、自动更新、系统睡眠唤醒事件、网络取消 UI、磁盘空间预检、七天滚动阶段日志；保留 JSONL 每轮记录。
- Ask 和不稳定/占用/超限文件仍保守停止该轮；没有做到同文件夹其他文件继续同步。LFS、子模块、符号链接/junction、非 UTF-8 文件名及不兼容命名不支持。
- 未做实际断电或编辑器并发写入验收，哈希核对和原子替换仍存在最终核对后的竞争窗口。
- UI 调试构建的 Parley/ICU 会输出中文复杂分词模型诊断；截图中文字正常。Release 不启用这项 ICU 调试打印；中文选词行为仍需专项验收。
- 原设计内存、空闲 CPU、1 万文件同步耗时尚未完成正式资源验收；可执行体积实测见下，仍超过目标。没有执行 cargo-audit/cargo-deny、Miri、Loom、模糊测试或覆盖率/变异测试，不能称依赖与安全审计已完成。
