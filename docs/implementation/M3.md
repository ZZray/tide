# M3 公开发布与云端安装包 / Public preview delivery

日期 / Date: 2026-10-18

## 交付范围 / Scope

- 公开源码仓库：[ZZray/tide](https://github.com/ZZray/tide)，开发分支为 `main`。
- 原创代码与双潮线品牌资源采用 MIT；依赖保留各自协议，Slint 使用免版税桌面条款并保留 AboutSlint。
- 中文与英文 README、技术说明、贡献指南和预览版发行说明。
- Windows x64 安装程序、便携 ZIP 和 SHA-256 清单，由 GitHub Actions 构建。
- `tide/test` 继续仅用于同步测试，没有代替开发分支。

The public repository includes bilingual documentation, original MIT-licensed
branding, and a Windows cloud packaging pipeline. `main` is the development
branch; `tide/test` remains a synchronization test branch.

## 配置共享 / Preference sharing

设置界面和 CLI 支持导出、检查、导入版本化的偏好文件，仅包含主题和通知。
文件可经已有同步文件夹传递；另一设备需要主动确认导入，不自动应用远端配置。
本机路径、远端地址、凭据、设备名、开机启动、同步规则及安全暂停状态不共享。

Only theme and notification preferences are portable. Import is explicit;
machine-specific settings and credentials remain local. The schema rejects
unknown fields and unsupported versions; exports do not overwrite existing files.

## 验证边界 / Verification boundaries

本地常规测试 46 项通过，格式、Clippy 严格检查和 PowerShell 语法检查通过。
设置页实际截图已检查。本轮没有重跑 M1 的 1000 轮压力测试。

本机 Cargo 包与构建缓存、Rust 子进程临时文件继续使用 `F:\cache\rust`；
云端 runner 使用自身临时与工作区磁盘，不要求本机 F 盘。

许可打包从锁定的依赖源码收集原文；缺失文件须由精确版本、源提交与 SHA-256
核验的上游文本补齐。`simd_helpers 0.1.0` 的上游无独立许可文件，保留原始
manifest 的 MIT/作者声明和标准 MIT 文本，具体边界见 [许可说明](../../licenses/README.md)。
文件缺失、版本不匹配或哈希错误会阻断打包；损坏许可文本的负向检查已通过。

Cloud install checks exercise a silent installation, the installed CLI version,
required notices and uninstallation. They do not constitute a full interactive
desktop acceptance test. Packages are an unsigned preview; macOS/Linux source
CI does not imply desktop or installer acceptance on those platforms.
