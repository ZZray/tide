# Tide v0.1.1 Preview / 桌面预览版

This preview adds in-app updates from GitHub Releases and fixes three issues found
while testing v0.1.0.

本版加入基于 GitHub Releases 的应用内更新，并修复 v0.1.0 实测中发现的三个问题。

## New / 新增

- **Automatic updates (installer builds).** Tide checks this repository's releases
  about a minute after start and then daily. A newer installer is downloaded in the
  background and verified against the release's `SHA256SUMS.txt`; nothing is installed
  until you choose **Restart to update** in the sidebar, the About dialog or the tray
  menu. A sync in progress finishes first, then setup runs silently and Tide starts
  again. Turn it off in Settings. Portable copies show the new version and a link to
  the release page. CLI: `tide update check`, `tide update install`.
- **自动更新（安装版）。** 启动约一分钟后检查一次，之后每天一次。新版本在后台下载，
  按同一发布的 `SHA256SUMS.txt` 校验；只有在侧栏、“关于”或托盘菜单点“重启以更新”后
  才安装。正在进行的同步会先完成，然后静默安装并重新打开 Tide。可在设置中关闭。
  便携版只提示新版本并给出发布页。命令行：`tide update check`、`tide update install`。

## Fixed / 修复

- Sync results now report files changed locally and uploaded in every case (first
  download and fast-forward included); the status line shows both counts.
- `tide diff` and the history diff show Chinese and other non-ASCII file names
  instead of escaped octal bytes.
- **Remote overwrites local** no longer publishes the replaced local version. It stays
  on this device under history (marked “仅保存在本机”) and can be restored from there.
  Replacing from an empty remote branch is refused.
- 同步结果在所有情况下（含首次下载和快进）都统计本地变化和上传数量，状态栏显示两者。
- `tide diff` 和历史差异直接显示中文等非 ASCII 文件名，不再是八进制转义。
- “远端覆盖本地”不再把被替换的本地版本推到远端；它只保存在本机历史里（标注“仅保存在
  本机”），可从历史恢复。远端分支为空时拒绝执行。

## Downloads / 下载

Choose `*-setup.exe` for a per-user installation (required for automatic updates), or
extract `*-portable.zip` completely and run `tide.exe`. `SHA256SUMS.txt` contains package
checksums. Packages are built and install/uninstall-tested by GitHub Actions and are
unsigned, so Windows SmartScreen may ask for confirmation.

选择 `*-setup.exe` 按用户安装（自动更新需要安装版），或完整解压 `*-portable.zip`
后运行 `tide.exe`。`SHA256SUMS.txt` 为校验值。安装包由 GitHub Actions 构建并做安装/
卸载检查，尚未签名，Windows SmartScreen 可能要求确认。

v0.1.0 has no updater: install v0.1.1 once by hand; later versions arrive automatically.
v0.1.0 没有更新功能，需手动安装一次 v0.1.1，之后的版本会自动推送。

## Preview limits / 预览边界

Windows installers only; macOS/Linux have source/CI builds. No LFS, symlinks,
submodules, built-in keyring or code signing. Ask-mode and unsupported/busy files
conservatively stop a folder's current synchronization round.

当前只发布 Windows 安装包；macOS/Linux 提供源码与 CI 构建。不支持 LFS、符号链接、
子模块、内置钥匙串或代码签名。Ask 冲突及不支持/占用文件会保守停止当前轮。
