# Tide v0.1.0 Preview / 桌面预览版

Tide is now available as an open-source Git document synchronization tool under
the MIT license. This is a Windows x64 preview with a Chinese desktop interface.

Tide 现以 MIT 开源发布。这是 Windows x64 中文桌面预览版。

## Included / 包含

- Slint desktop, Windows tray, background synchronization and configuration reload.
- Real Git SSH/HTTPS synchronization, conflict copies, history differences,
  restore/export and recoverable overwrite operations.
- Explicit theme/notification preference export/import; machine-specific settings
  and credentials remain local.
- Original double-tide logo and multi-resolution application/tray icons.
- Chinese/English documentation, MIT license and bundled third-party notices.

- Slint 桌面、Windows 托盘、后台同步与配置热加载。
- 真实 Git SSH/HTTPS 同步、冲突副本、历史差异、恢复/导出和可撤销覆盖。
- 可主动共享主题/通知偏好，设备配置与凭据保持独立。
- 原创双潮线 Logo、多尺寸应用/托盘图标，中英文说明及许可清单。

## Downloads / 下载

Choose `*-setup.exe` for a per-user installation, or extract `*-portable.zip`
completely and run `tide.exe`. `SHA256SUMS.txt` contains package checksums. Packages
are built and install/uninstall-tested by GitHub Actions. Preview binaries are unsigned.

选择 `*-setup.exe` 按用户安装，或完整解压 `*-portable.zip` 后运行 `tide.exe`。
附带 `SHA256SUMS.txt` 校验值。安装包由 GitHub Actions 编译并检查安装/卸载，尚未签名。

## Preview limits / 预览边界

Windows installers only; macOS/Linux have source/CI builds. No LFS, symlinks,
submodules, built-in keyring or automatic updates. Ask-mode and unsupported/busy
files conservatively stop a folder's current synchronization round. Resource and
performance goals remain under evaluation. See the README for details.

当前只发布 Windows 安装包；macOS/Linux 提供源码与 CI 构建。不支持 LFS、符号链接、
子模块、内置钥匙串或自动升级。Ask 冲突及不支持/占用文件会保守停止当前轮。
资源和性能目标仍在评估，具体见 README。
